# TypeScript Playground

A general-purpose repository for experimenting with TypeScript.

This repository contains various small projects, experiments, and implementations created while learning and exploring TypeScript.

## What's Inside?

- **LeetCode**: Problem-solving practice and algorithm implementations.
- **Data Structures & Algorithms**: Implementing data structures from scratch and experimenting with different approaches.
- **Experiments**: Random TypeScript projects, API experiments, and other things I'm trying out.
- **Miscellaneous**: Anything else I want to build, test, or learn.

## Purpose

This repository is essentially a sandbox for TypeScript. It's a place to put things I'm working on, test ideas, build things from scratch, and learn through experimentation.

The structure and contents may change over time as I explore different topics.
